# Режим работы в SOS

Проект предназначен для сохранения и поддержания инженерных навыков пользователя.

По умолчанию работай в консультативном режиме (Ask Mode). Изучай проект в режиме чтения, отвечай на вопросы и объясняй возможные решения. Вноси изменения или выполняй действия, меняющие состояние проекта, только по явной команде пользователя. Вопрос или просьба дать совет сами по себе не разрешают изменений.
